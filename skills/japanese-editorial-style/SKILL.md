## 🏛️ 第一章：日系排印四大底层法则 (The CAP Directives)

日本知名设计公司 CAP 及主流潮流杂志的经典版面底层逻辑：

### 1. 压舱字阶法则 (Visual Hierarchy)
- **主标题占据感**：主标题字号必须 $\ge$ 正文字号的 **1.5 倍**；封面大主标宽度应占据整体画幅宽度的 **20% ~ 50%**，形成稳定的视觉锚点。
- **行距黄金比**：正文行距严格锁定在字高的 **120% ~ 150%（中文字建议 1.3 倍）**，绝不出现字行粘连拥挤。

### 2. 50:50 留白与模块网格 (Grid & Breathing Space)
- **网格分割**：
  - **经典双栏**：1/3 负空间（色块/纯净砖墙/阴影区） + 2/3 主画面（人物或场景大片）；
  - **单列全幅**：主图满版，文字严格贴边缘对齐（如右边缘竖排、顶部紧贴安全线）。
- **绝对安全边距**：封面四边各预留不低于 **20~30px（竖屏等比放大）** 的呼吸空白区，拒绝文字贴边溢出。

### 3. Gothic（黑体）与 Mincho（明朝体）的对话
- **标题**：大量使用欧美高密度无衬线（Futura Bold, Helvetica Neue, Avenir Heavy），传递都市与国际感；
- **副标与注释**：搭配带有手工温润感的衬线/明朝体（游明朝、源ノ明朝）或细无衬线；
- **竖排破局**：在横向排版中插入 1~2 组短句竖排，赋予画面天然的东方韵味。

### 4. 色彩配比：90% 基础色 + 10% 点缀跳色
- 严禁全屏色彩杂乱，大面积（90%）由自然环境色、冷灰、素麻、纯白或极黑主导；
- 仅用 10% 的点睛色（如珊瑚红、薄荷蓝、朱砂色、柠檬黄）打破沉闷。

### 1. 都市休闲风（Urban Casual / Cityboy / 《POPEYE》）
- **核心受众**：街头潮流青年、摄影师、Cityboy、复古穿搭博主。
- **色彩规范 (HEX)**：
  - 主基调：`#40537C`（都市靛蓝）、`#DDDDDD`（轻质冷灰）、`#222222`（深炭黑）；
  - 点缀跳色：`#E63946`（POPEYE 珊瑚红）。
- **字体推荐**：
  - 主标题：`Futura Bold` / `Avenir Heavy` *(免费替代: Montserrat Bold)*；
  - 副标题：`Rockwell` / `Arvo` *(免费替代: Noto Serif)*；
  - 中文正文：`苹方 / 思源黑体 (Noto Sans SC) Medium`。
- **版式与质感**：
  - 左侧 1/3 留白放置文案，右侧 2/3 为街头自然光抓拍；
  - 必须叠加 **35mm 细颗粒胶片噪点** 与轻微褪色暗角。

### 2. 高级时尚风（High Fashion / 先锋艺术 / 《GINZA》）
- **核心受众**：时装爱好者、先锋视觉设计师、高定买手。
- **色彩规范 (HEX)**：
  - 主基调：`#F7F7F7`（象牙米白）、`#333333`（高定暗灰）；
  - 冲击跳色：`#FF4081`（高饱和艳粉）、`#00ACC1`（冷感薄荷蓝）。
- **字体推荐**：
  - 主标题：`Avenir Next Heavy` / `Didot` *(免费替代: Roboto Black / Playfair Display)*；
  - 辅助字：手写毛笔书法体 / 艺术刷痕字体；
  - 中文正文：`方正兰亭纤黑` / `思源宋体 (Noto Serif SC) Light`。
- **版式与质感**：
  - 满版高质感肖像，右侧单边竖排杂志大字；
  - 融入水墨晕染、油画刀刮痕或彩墨涂鸦，艺术破坏传统死板构图。

### 3. 甜美 Pop 风（Kawaii Pop / 原宿潮流 / 动漫亚文化）
- **核心受众**：Z世代、二次元受众、手账/萌物爱好者。
- **色彩规范 (HEX)**：
  - 马卡龙糖果色系：`#FFB3BA`（淡樱粉）、`#BAE1FF`（天际蓝）、`#B5EAEA`（薄荷绿）、`#FFFFBA`（奶油黄）。
- **字体推荐**：
  - 主标题：`Rounded M+ 1c` / `游丸ゴシック` *(免费替代: 站酷快乐体 / Kosugi Maru)*；
  - 副标题：`Segoe UI Rounded` / `Arial Rounded MT`。
- **版式与质感**：
  - 中心对齐或活泼贴纸拼贴（Sticker collage）；
  - 配套水彩浅晕染、星芒几何点缀、圆角高光白边。

### 4. 日式和风（Traditional Wabi-sabi / 旅人手记 / 《Casa BRUTUS》）
- **核心受众**：建筑/空间设计师、茶道与手工艺人、旅行人文摄影师。
- **色彩规范 (HEX)**：
  - 传统和色：`#264653`（深藏青）、`#F4E1D2`（和纸米色）、`#E63946`（神社朱砂）、`#2A9D8F`（苔藓孔雀青）。
- **字体推荐**：
  - 主标题：`源ノ明朝体 (Source Han Serif)` / `Hiragino Mincho Pro`；
  - 副标题：`Yu Gothic (游ゴシック)` / `Noto Sans CJK`。
- **版式与质感**：
  - 两栏宁静分割，大量东方留白（空间透气度 > 40%）；
  - 文字坚持**绝对竖排**；叠加素麻织物底纹、微透和纸（Washi Paper）纤维质感。

### 5. 极简现代（Minimalist Modern / 工业机能 / Peak Design 美学）
- **核心受众**：数码发烧友、工业设计师、EDC 玩家、极简主义者。
- **色彩规范 (HEX)**：
  - 极致黑白灰：`#FFFFFF`（纯净冷白）、`#000000`（曜石黑）、`#4F4F4F`（钛金属中灰）、`#CCCCCC`（轻铝银）。
- **字体推荐**：
  - 主标题：`Helvetica Neue Bold` / `Inter Tight Bold` *(免费替代: Arial Bold)*；
  - 副标题：`Open Sans Regular` / `Roboto Mono`（代码参数标签感）。
- **版式与质感**：
  - 瑞士国际主义网格系统，极度严谨的左对齐或中心对齐；
  - 零多余杂纹，纯粹依赖光影对比、材质反光与几何标尺线。

## 🛠️ 第三章：移动端与社交平台（小红书/IG/B站）特化强化规则

缩略图在手机信息流中会缩小至 1/8 尺寸，必须执行以下补强原则：

1. **粗度补偿法则（+20%~30%）**：
   - 在桌面端看着纤细优雅的小字，在手机上会彻底消失；核心标题字重必须增加一档（从 Medium 提升至 Bold/Heavy）。
2. **边缘微硬影（Ambient Drop Shadow）**：
   - 浅色文字放置于复杂背景（如街景、砖墙）时，禁止使用大面积廉价黑色羽化投影；
   - 采用：`1px ~ 2px` 扩散、50%~70% 不透明度的高斯暗影，或 `0.5px` 极细暗调描边，确保字迹锐利。
3. **白边贴纸破局法（Sticker Cutout）**：
   - 拍摄单品（如相机、包袋、咖啡杯）切入画面时，将产品抠图后附带 `2px ~ 4px` 纯白硬质描边，置于手刷白色水彩底衬上，制造波普杂质感与图层纵深。
4. **双行标绘公式**：
   - `// TECH SPEC : 英文大写功能标签`
   - `中文卖点人话短句（严控 8~12 字以内）`

## 🚫 第四章：绝对禁忌清单 (Banned Anti-Patterns)

- ❌ **严禁渐变彩虹字与金箔特效**（典型低俗营销感）。
- ❌ **严禁高饱和亮黄大粗描边**（山寨解说短视频感）。
- ❌ **严禁无呼吸感满屏贴纸**（破坏日杂的克制平衡）。
- ❌ **严禁 AI 塑料光滑磨皮**（必须有 35mm 真实环境光与物理颗粒感）。
- ❌ **严禁连续等长排版**（短句破行，长句呼吸，制造视线跳跃节奏）。
