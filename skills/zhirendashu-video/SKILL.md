## 剪辑美学与核心原则

> **核心判定法则：拒绝廉价网红感，拒绝 AI 塑料感与过载花字。**

### 参考调性
- **北野武式镜头克制**：适度留白，不盲目乱切，注重主体画面呼吸感。
- **昭和摄影杂志与 DV 纪录片**：高对比胶片颗粒、真实的物理环境声音细节。
- **真实保留**：保留取景器视线、真实操作按键声与自然呼吸。

### 关键规则
1. **前 3 秒黄金 Hook**：开场 3 秒内使用强拉镜或关键亮点瞬间抓住用户视线。
2. **字幕样式**：白色主体 + 少量昆丁血红/暖橙强调。禁止使用满屏贴纸与花字。
3. **音效与音乐**：挂载高清晰度 ASMR 音效（撕膜/磁吸/按键/风声），BGM 保持沉浸不抢口播。

## 自动化工作流 (Workflow)

当用户提出视频制作需求（如：“帮我制作小红书神牛灯开箱视频”）：

1. **素材分析**：使用 FFmpeg 与 OpenCV 检查素材的分辨率、帧率与色彩空间。
2. **口播擦除与字幕生成**：调用 Python `faster-whisper` 识别口播，自动切除无声停顿（>1.2s）与冗余废话，生成 `.srt` 字幕。
3. **剪映工程构建**：调用 `pyJianYingDraft` 自动生成竖屏 9:16 剪映 Pro 工程。
4. **运镜与音效注入**：
   - 挂载 3D 浮动微旋转关键帧 (Scale + Rotation)。
   - 自动在音效轨同步对齐 4 大 ASMR 开箱音效。
   - 自动居中画面并上移 4% 避开 IG / 小红书 UI 遮挡区。
5. **输出与默认链路防错 (Validation & Output)**：
   - 自动校验 `materials.videos` 的媒体路径，防止包含 `##_material_placeholder...##` 导致的时间线灰色/媒体丢失。
   - 生成可以直接在剪映专业版中打开并编辑的草稿工程，并同步生成小红书标题、文案与 TAG。
