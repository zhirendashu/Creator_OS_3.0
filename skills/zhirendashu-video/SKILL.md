## 剪辑美学与核心原则

> **核心判定法则：拒绝廉价网红感，拒绝 AI 塑料感与过载花字。**

### 参考调性
- **北野武式镜头克制**：适度留白，不盲目乱切，注重主体画面呼吸感。
- **昭和摄影杂志与 DV 纪录片**：高对比胶片颗粒、真实的物理环境声音细节。
- **真实保留**：保留取景器视线、真实操作按键声与自然呼吸。

### 关键规则
1. **零硬编码模板字幕法则**：彻底禁止使用代码预设/营销模板字幕（如 `⚡ //` 或旧产品描述）。每次收到新产品，必须先调用网络搜索工具（`search_web`）检索该特定产品的真实参数与特点，结合真实观察生成客观字幕。
2. **前 3 秒黄金 Hook**：开场 3 秒内使用强拉镜或关键亮点瞬间抓住用户视线。
3. **字幕样式**：白色主体 + 少量昆丁血红/暖橙强调。禁止使用满屏贴纸与营销感硬编字。
4. **音效与音乐**：挂载高清晰度 ASMR 音效（撕膜/磁吸/按键/风声），BGM 保持沉浸不抢口播。

## 34.53s 完播率节奏控制法则

> 小红书视频完播率的黄金时长区间：**30~40 秒**。每一秒都要有内容密度。

### 节奏分配模板（总时长 ≈ 35s）

| 时间段 | 时长 | 内容 | 剪辑手法 |
|:---|:---:|:---|:---|
| 钩子段 | 0~3s | 强视觉开场（产品最美角度/意外动作） | 快切 / 极速推近 |
| 建立段 | 3~8s | 产品介绍 + 材质质感展示 | 慢推 + ASMR 音效 |
| 核心段 | 8~25s | 主体功能演示 + 口播 | 正常节奏，字幕同步 |
| 转折段 | 25~30s | 真实缺点/惊喜点（制造记忆点） | 插入特写 |
| 收尾段 | 30~35s | 结论 + 留悬念（引发评论/收藏） | 慢镜头 / 定格 |

### 废话擦除判断标准

以下内容判定为「废话」，必须在剪辑中直接删除：
- ❌ 开场自我介绍（「大家好我是植人大树」）
- ❌ 过渡废话（「接下来我们来看...」「好了现在...」）
- ❌ 停顿超过 0.8s 的无效沉默
- ❌ 重复说了两遍的同一意思
- ❌ 结尾呼吁关注点赞（改为字幕提示即可）

## 自动化工作流 (Workflow)

当用户提出视频制作需求（如："帮我制作小红书神牛灯开箱视频"）：

### 1. 素材分析
```python
from ffmpeg_preprocessor import extract_audio_wav, crop_to_vertical_916, sample_keyframes
import subprocess

# 检测素材分辨率、帧率与色彩空间
result = subprocess.run(
    ['ffprobe', '-v', 'quiet', '-print_format', 'json',
     '-show_streams', '-show_format', 'input.MOV'],
    capture_output=True, text=True
)
# 提取音轨用于 Whisper 识别
wav_path = extract_audio_wav('input.MOV', 'voice.wav')
# 如需竖屏转换
vertical_mp4 = crop_to_vertical_916('input.MOV', 'output_916.mp4')
# 关键帧抽样用于内容分析
frames = sample_keyframes('input.MOV', 'frames_dir', fps=1.0)
```

### 2. 废话擦除与字幕生成
```python
from ffmpeg_preprocessor import remove_silence
from auto_subtitle import transcribe_to_srt, inject_subtitles_to_draft

# 静音擦除（去掉停顿 > 0.8s 的无效沉默）
clean_mp4 = remove_silence('input.MOV', 'clean.mp4', noise_db=-35.0, min_duration=0.4)
# 语音识别生成 SRT
srt_path = transcribe_to_srt('voice.wav', language='zh', device='cuda')
```

### 3. 剪映工程构建
```python
from auto_edit_engine import AutoEditEngine
engine = AutoEditEngine()
engine.build_vertical_draft(
    video_path='clean.mp4',
    srt_path=srt_path,
    text_preset='01_pulp_amber',
    eagle_sfx_keywords=['Film Sound', '漏光', 'VHS']
)
```

### 4. 运镜与音效注入
- 挂载 3D 浮动微旋转关键帧 (Scale + Rotation)。
- 自动在音效轨同步对齐 4 大 ASMR 开箱音效（撕膜/磁吸/按键/开盖）。
- 自动居中画面并上移 4% 避开 IG / 小红书 UI 遮挡区。

### 5. 输出与默认链路防错 (Validation & Output)
- 自动校验 `materials.videos` 的媒体路径，防止包含 `##_material_placeholder...##` 导致的媒体丢失。
- 生成可以直接在剪映专业版中打开并编辑的草稿工程。
- 同步生成小红书标题、文案与 TAG（调用 `xiaohongshu-skills`）。

## 视频内容评分标准（用于素材分析与剪辑决策）

| 维度 | 满分 | 评分标准 |
|:---|:---:|:---|
| 钩子强度（前 3s） | 25 | 有强视觉冲击/悬念/意外感 → 20-25；平铺直叙 → 0-10 |
| 音效真实感 | 20 | 100% 使用真实 ASMR → 18-20；有电子合成音 → 0-10 |
| 节奏密度 | 20 | 每秒有信息变化 → 18-20；有超过 1s 的静默段 → 0-10 |
| 字幕可读性 | 15 | 安全区内、无遮挡、高对比 → 13-15 |
| 美学克制度 | 20 | 无过载贴纸/营销花字/特效堆砌 → 18-20 |

**总分 ≥ 85：可发布 | 70-84：需微调 | < 70：重剪**
