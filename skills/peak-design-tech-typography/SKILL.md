# 📐 Peak Design 极简工业科技花字 Skill (Tech Typography)

> **设计宗旨**：克制、精致、人话、科技感。  
> 彻底告别土味大字与过度花哨营销贴纸，还原顶级工业设计品牌的现代科技编排美学。

---

## 📌 核心排版参数规范

```
┌────────────────────────────────────────────────────────────────────────┐
│                        9:16 竖屏安全视线带                               │
│                                                                        │
│                      (主画面：人像 / 单品大片)                            │
│                                                                        │
│   Y = -0.68  ───────────────────────────────────────────────────────  │
│              ╭────────────────────────────────────────────────────╮   │
│              │ // SPEC 01 : WEATHERPROOF RECYCLED NYLON           │   │
│              │ 防泼水回收尼龙 · 突遇暴雨也能从容漫游                │   │
│              ╰────────────────────────────────────────────────────╯   │
│                                                                        │
│   Y = -0.75  ───────────────────────────────────────────────────────  │
│              (常规口播对齐字幕轨道)                                      │
└────────────────────────────────────────────────────────────────────────┘
```

### 1. 双行技术编排架构
- **第一行（技术标号与英文硬件规格）**：
  - 格式：`// SPEC [序号] : [全大写英文核心硬件/材质特性]`
  - 范例：`// SPEC 01 : 315g FEATHERLIGHT BUILD`
  - 字体：`Roboto Mono Bold` / `DIN 1451 Mittelschrift` / `Inter Tight Bold`
  - 字重与字号：`4.2pt ~ 4.8pt` 纯白晶体小字，字母间距 `Tracking +15%`
- **第二行（摄影师人话卖点短句）**：
  - 格式：`[核心体验] · [场景化人话]`
  - 范例：`仅一听可乐重 · 彻底解放肩膀的城市漫步`
  - 字体：`思源黑体 (Noto Sans SC) Medium` / `苹方 Medium`
  - 字重与字号：`5.2pt ~ 5.8pt`，行长严格控制在 12 个汉字以内。

### 2. 胶囊底衬与阴影质感
- **胶囊衬底（Capsule Cushion）**：
  - 填充色：`#18191C`（炭黑石墨色）
  - 不透明度：`52% ~ 58%`（微透背景环境，不抢戏）
  - 圆角半径：`6px ~ 8px`
  - 内边距：`上下 6px，左右 14px`
- **硬质微阴影（Ambient Shadow）**：
  - `0px 1px 3px rgba(0, 0, 0, 0.45)`，拒绝廉价高斯模糊大晕染。

### 3. 视线带坐标安全区
- **Y 轴定位**：严格锁定在剪映/视频坐标 `Y = -0.68`（黄金视线带）；
- **层级避让**：高于常规口播字幕轨道（`Y = -0.75`），低于人物胸口视线线，确保不遮挡模特面部与产品主体。

### 4. 动效规范（呼吸出入）
- **入场**：`0.3s` 线性渐显（Fade In） + 微量横向位移（+2%）；
- **驻留**：随讲解段落持续 `1.8s ~ 2.5s`；
- **退场**：`0.3s` 柔和渐隐（Fade Out）。
